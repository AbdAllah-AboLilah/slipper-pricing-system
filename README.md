# نظام تسعير السليبر — Slipper Pricing ERP

نظام PWA محلي Local-First لتسعير فواتير شراء السليبر وFoot Wear، مبني على IndexedDB وبمعمارية Modular.

## اسم GitHub المقترح
`slipper-pricing-erp`

## المزايا
- يعمل على الكمبيوتر والموبايل وiPhone/Android.
- يعمل Offline بعد تحميل التطبيق.
- IndexedDB للتخزين المحلي.
- حفظ تلقائي سريع للمسودة.
- أرقام فواتير يومية.
- Slipper / Winter مع حفظ النوع الافتراضي.
- نسبة ربح قابلة للتعديل.
- شرائح أسعار مستقلة وقابلة للتعديل.
- بحث داخلي يحاكي منطق VLOOKUP.
- موردون وأصناف ERP بدون بيانات seed مسبقة.
- استيراد Master ERP بصف عناوين قابل للاختيار وMapping للحقول ومعاينة قبل الاستيراد.
- فصل سعر الشراء عن التكلفة الفعلية، مع خصم المورد وأساس ربح قابل للاختيار.
- سعر البيع = السعر قبل الخصم كحقل واحد، والسعر بعد الخصم مستقل.
- LRP وLRB ضمن البيانات الأساسية والتصدير.
- واجهة Mobile Cards بدون زحلقة أفقية للبيانات والفاتورة.
- استيراد CSV/Excel عند توفر SheetJS.
- تصدير ERP بنفس ترتيب الأعمدة الذي تحدده.
- صورة ومشاركة وطباعة حرارية.
- رفع أصل الفاتورة وحفظه محليًا.
- حالة ERP ورقم فاتورة ERP.
- Backup / Restore.

## النشر على GitHub Pages
1. ارفع محتويات المجلد إلى Repository.
2. فعّل GitHub Pages من Branch الرئيسي والمجلد `/root`.
3. افتح رابط Pages مرة واحدة من الإنترنت حتى يُسجّل Service Worker.
4. بعد ذلك يمكن استخدام النظام محليًا مع IndexedDB.

## تحديث الإصدار
عند أي تحديث:
1. غيّر `APP_VERSION` داخل `src/core/utils.js`.
2. غيّر `CACHE` داخل `sw.js` إلى رقم الإصدار الجديد.
3. حدّث `package.json` و`CHANGELOG.md`.
4. ارفع التغييرات إلى GitHub.

## ملاحظة Excel
استيراد `.xlsx/.xls` يستخدم SheetJS من CDN عند توفر الاتصال. CSV يعمل بدون ذلك. بعد تحميل التطبيق مع الاتصال يمكن للمتصفح الاحتفاظ بالملفات الأساسية محليًا، لكن الاعتماد على CDN للاستيراد لا يُعتبر بديلًا عن تضمين مكتبة Excel داخل المشروع إذا كان المطلوب Offline Excel Import بنسبة 100%.
